# SL006: Disconnected branch

## Overview

- **Code**: `SL006`
- **Category**: `graph`
- **Default Severity**: `warning`
- **Default Repairability**: `manual`
- **Summary**: Report unreachable components without assuming they should be merged.

## Invariant

All events in the session graph must be reachable from the root event or connect directly to a recognized terminal head.

## Cause

Abandoned branches from speculative execution, or incomplete compaction retaining unreachable detached subtrees.

## False-Positive Notes

Agent runtimes may intentionally store archived side-branches for introspection or debugging.

## Recipe or Manual Path

Warning/manual. Salvage repair allows pruning disconnected branches via `unresolvable-branch-amputate`.

Policy: *Unreachable components may be intentional subtrees; manual review required.*
