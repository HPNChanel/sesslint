# SL103: Reused tool-call ID

## Overview

- **Code**: `SL103`
- **Category**: `pairing`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Same ID maps to non-equivalent calls.

## Invariant

A tool-call ID must uniquely identify a single tool invocation within the session.

## Cause

Static or non-random tool-call ID generation, counter resets across worker threads, or duplicate invocation templates.

## False-Positive Notes

Idempotent retries reusing the same call ID with identical arguments.

## Recipe or Manual Path

Manual review. Automated repair cannot disambiguate which call maps to which result without assuming execution semantics.

Policy: *Conflicting tool call IDs cannot be disambiguated safely without operator intervention.*

## Example

```json
{"id": "c1", "type": "tool_call", "correlation_id": "call_id_1", "tool": "read"}
{"id": "c2", "type": "tool_call", "correlation_id": "call_id_1", "tool": "write"}
```
