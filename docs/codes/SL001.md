# SL001: Malformed record

## Overview

- **Code**: `SL001`
- **Category**: `syntax`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Report record ordinal plus line and byte offset where available.

## Invariant

Every non-empty nonterminal line in a session stream must decode as valid UTF-8, strictly comply with the max-line byte limit, contain no NUL bytes, and parse into a well-formed JSON object within recursion limits.

## Cause

A nonterminal line was corrupted, truncated mid-stream, or injected with illegal binary data (such as NUL bytes or unescaped control characters) followed by subsequent lines.

## False-Positive Notes

If a client improperly serializes multiline log messages containing unescaped raw newlines, downstream consumers will observe subsequent lines as malformed records.

## Recipe or Manual Path

Nonterminal malformed records cannot be safely repaired without arbitrary synthesis or data loss; manual operator intervention is strictly required.

Policy: *Nonterminal malformed records block automated repair; cannot be overridden to deterministic.*

{"id": "evt_3", "role": "assistant"}
