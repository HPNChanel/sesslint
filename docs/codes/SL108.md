# SL108: Compaction split pair

## Overview

- **Code**: `SL108`
- **Category**: `pairing`
- **Default Severity**: `warning`
- **Default Repairability**: `manual`
- **Summary**: A retained compaction boundary separates a required atomic pair.

## Invariant

Compaction boundaries must not sever an atomic tool call from its matching tool result.

## Cause

Token-budget compaction truncated context between a tool call and its result, placing one half in summary and the other in active context.

## False-Positive Notes

None.

## Recipe or Manual Path

Conservative repair: `compaction-projection-reunion` reunites pairs across single boundaries. Salvage repair: `torn-compaction-project` if one half was discarded.

Policy: *May be repairable by compaction reunion recipe if both records are present.*

## Example

```json
tool_call
--- compaction boundary ---
tool_result
```
