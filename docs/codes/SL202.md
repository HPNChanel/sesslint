# SL202: Accepted terminal output not durable

## Overview

- **Code**: `SL202`
- **Category**: `checkpoint`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Runtime state indicates accepted output that the history cannot recover.

## Invariant

Terminal output accepted and displayed to the user must be durably stored in the session history.

## Cause

Assistant generated response displayed in user interface, but crash occurred before durable write to disk.

## False-Positive Notes

Draft or preview responses that were canceled by the user before acceptance.

## Recipe or Manual Path

Manual review. Resuming without durable output risks prompting duplicate actions.

Policy: *Missing accepted terminal output risks re-entering model or duplicate actions.*

## Example

```json
Metadata reports terminal message ID "msg_final" delivered, but "msg_final" is absent from event stream.
```
