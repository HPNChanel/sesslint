# SL301: Unsupported format version

## Overview

- **Code**: `SL301`
- **Category**: `compatibility`
- **Default Severity**: `error`
- **Default Repairability**: `unsupported`
- **Summary**: Adapter recognizes the family but not the version safely enough to repair.

## Invariant

Session files must declare a format schema version supported by the active adapter.

## Cause

Ingesting a session file generated by an older deprecated version or a newer unsupported version of the provider CLI.

## False-Positive Notes

Minor backwards-compatible version bumps when using adapters with strict version matching.

## Recipe or Manual Path

Unsupported. The tool halts with SL301 rather than guessing schema semantics.

Policy: *Never silently guess or fall back to an approximate schema version.*

## Example

```json
{"version": 999, "events": []}
```
