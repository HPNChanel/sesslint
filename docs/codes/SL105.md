# SL105: Tool result precedes call

## Overview

- **Code**: `SL105`
- **Category**: `pairing`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Ordering is structurally impossible under the selected profile.

## Invariant

A tool result cannot appear prior to its corresponding tool call in stream or causal graph order.

## Cause

Asynchronous write race conditions, clock skew during ingestion, or out-of-order log buffering.

## False-Positive Notes

None under causal DAG traversal.

## Recipe or Manual Path

Manual review. Inverting event order automatically risks violating causal dependencies.

Policy: *Causality inversion; reordering requires profile-specific replay analysis.*

## Example

```json
Record 1: tool_result (call_id="call_x")
Record 2: tool_call (call_id="call_x")
```
