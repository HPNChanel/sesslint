# SL003: Duplicate event ID

## Overview

- **Code**: `SL003`
- **Category**: `identity`
- **Default Severity**: `warning`
- **Default Repairability**: `deterministic`
- **Summary**: Distinguish byte-identical duplicates from conflicting duplicates.

## Invariant

All event identifiers in the session must be unique within the session directed acyclic graph.

## Cause

Log shipping retry duplication, faulty UUID/ID generation in agent runtimes, or uncoordinated concurrent writers emitting identical event IDs.

## False-Positive Notes

Byte-identical duplicates are benign idempotent appends, classified as warnings under the neutral profile. Conflicting duplicates (same ID with diverging contents) are fatal errors.

## Recipe or Manual Path

Byte-identical duplicates can be safely resolved using the `identical-duplicate-collapse` recipe. Conflicting duplicates require manual review.

Policy: *Defaults to warning/deterministic for byte-identical duplicates; detectors must override to error/manual when duplicates have conflicting contents.*

## Example

```json
{"id": "evt_1", "type": "turn", "payload": "A"}
{"id": "evt_1", "type": "turn", "payload": "A"}
```
