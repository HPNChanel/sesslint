# SL107: Provider adjacency violation

## Overview

- **Code**: `SL107`
- **Category**: `pairing`
- **Default Severity**: `warning`
- **Default Repairability**: `manual`
- **Summary**: Pair exists but does not satisfy the selected provider’s placement rule.

## Invariant

Tool results must conform to provider-mandated adjacency constraints relative to their tool calls.

## Cause

Intervening user messages, system messages, or unassociated assistant thoughts placed between a tool call and its result.

## False-Positive Notes

Neutral profile allows flexible placement; strict provider profiles (OpenAI/Claude strict) enforce strict adjacency.

## Recipe or Manual Path

Warning/manual. Reordering turns requires understanding dialogue flow.

Policy: *Adjacency warning depending on selected provider/runtime profile requirements.*

## Example

```json
assistant: tool_call
user: "wait what?"
tool_result: "success"
```
