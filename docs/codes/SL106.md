# SL106: Cross-branch tool pairing

## Overview

- **Code**: `SL106`
- **Category**: `pairing`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Call and result belong to incompatible interaction or agent scopes.

## Invariant

Tool calls and their corresponding results must reside within the same causal branch and execution context.

## Cause

Interleaved execution traces from parallel subagents or branch forks mistakenly sharing a linear stream.

## False-Positive Notes

Shared global tool contexts accessed across subagents if logged into a flat non-branching session.

## Recipe or Manual Path

Manual review. Merging or re-pointing cross-branch pairs automatically could corrupt independent lineages.

Policy: *Interleaved agent scopes cannot be safely unified without trace knowledge.*

## Example

```json
Branch A: tool_call("calc")
Branch B: tool_result("calc")
```
