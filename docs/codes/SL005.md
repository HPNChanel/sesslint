# SL005: Parent cycle

## Overview

- **Code**: `SL005`
- **Category**: `graph`
- **Default Severity**: `fatal`
- **Default Repairability**: `unsupported`
- **Summary**: Emit a deterministic cycle path.

## Invariant

The session parent-child graph must be an acyclic directed tree rooted at an initial event.

## Cause

Corrupted parent references, improper graph stitching, or synthetic circular replay generation producing circular parent references.

## False-Positive Notes

None. Graph cycles violate causal time ordering.

## Recipe or Manual Path

Refused under both policies. The detector emits `unsupported` for SL005, and the planner blocks `unsupported` findings unconditionally — under conservative *and* salvage policy. The registered recipes `unresolvable-branch-amputate` and `terminal-suffix-discard` nominally cover SL005, but they are not reachable from real detector output (only crafted findings/plans can invoke them); the salvage path those recipes provide is reachable for `SL006` disconnected components instead. The only remedy for a cycle is manual: edit the session to break the circular parent references, then re-run `sesslint check`.

Policy: *Cycles break causal DAG ordering completely; fatal and unsupported by default.*
