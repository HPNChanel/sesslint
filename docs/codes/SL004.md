# SL004: Missing parent

## Overview

- **Code**: `SL004`
- **Category**: `graph`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Identify the missing reference and affected descendants.

## Invariant

Every non-root event in the session DAG must declare a parent identifier that points to a known, valid event within the session.

## Cause

History truncation, shallow compaction dropping parent events, or out-of-order log record collection missing upstream nodes.

## False-Positive Notes

Pruned subtrees or bounded history windows where historical ancestry was severed intentionally without re-pointing root events.

## Recipe or Manual Path

The detector checks the complete event-id index. When the parent is absent,
no full-id-equality candidate can exist, so this finding is always manual.
Restore missing source records from an independently trusted copy or inspect
the intended ancestry. The registered `proven-unique-parent-restore` recipe
remains a guarded primitive; current SL004 findings cannot authorize it.
Proximity, matching content and id prefixes are not proof of parentage.

Policy: *Repair requires proven unique predecessor satisfying full equality and confinement; manual when ambiguous or unconfined.*
