# SL101: Orphan tool result

## Overview

- **Code**: `SL101`
- **Category**: `pairing`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Result references no call in the permitted branch and replay window.

## Invariant

Every tool result event must correlate to an antecedent tool call event within the active branch and replay window.

## Cause

Compaction dropped the tool call event while retaining the result, or an external proxy injected results directly without logging the request.

## False-Positive Notes

Adapters failing to parse tool call IDs or correlation IDs from proprietary format payloads.

## Recipe or Manual Path

Conservative repair refuses automated synthesis or deletion because an orphan result may be the sole evidence of real-world mutation. Manual review required.

Policy: *Orphan result may be the only evidence of completed external action; conservative repair refuses.*

## Example

```json
{"id": "res_1", "type": "tool_result", "correlation_id": "call_unknown"}
```
