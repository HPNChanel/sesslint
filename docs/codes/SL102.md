# SL102: Dangling tool call

## Overview

- **Code**: `SL102`
- **Category**: `pairing`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Required result is absent before the next disallowed boundary.

## Invariant

Every tool call event must be paired with a corresponding tool result event before non-concurrent conversation boundaries.

## Cause

Session terminated while a tool was executing, tool execution crashed, network timeout occurred, or result logging failed.

## False-Positive Notes

Long-running asynchronous background tools that span beyond the immediate conversation turn.

## Recipe or Manual Path

Conservative repair refuses to synthesize unconfirmed results. Salvage repair allows truncation via `side-effect-unknown-truncate` only with explicit operator acknowledgment.

Policy: *Dangling tool call execution state unknown; conservative repair refuses synthesis.*

## Example

```json
{"id": "call_1", "type": "tool_call", "correlation_id": "call_1", "tool_name": "bash"} (no result follows)
```
