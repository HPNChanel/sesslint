# SL007: Ambiguous session head

## Overview

- **Code**: `SL007`
- **Category**: `graph`
- **Default Severity**: `warning`
- **Default Repairability**: `manual`
- **Summary**: Report multiple plausible terminal heads.

## Invariant

A linear session replay must identify a single unambiguous active terminal head.

## Cause

Multiple terminal leaves generated through concurrent branches, unmerged forks, or missing head pointers in session metadata.

## False-Positive Notes

Branching conversation graphs inherently have multiple leaves; this is only an ambiguity when linear replay is required.

## Recipe or Manual Path

Warning/manual. The operator must specify the target branch head for linearization or repair.

Policy: *Multiple terminal leaf events require operator choice of replay branch.*

## Example

```json
{"id": "1", "parent_id": null}
{"id": "2A", "parent_id": "1"}
{"id": "2B", "parent_id": "1"} (both 2A and 2B are leaves)
```
