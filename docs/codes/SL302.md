# SL302: Unknown critical record

## Overview

- **Code**: `SL302`
- **Category**: `compatibility`
- **Default Severity**: `error`
- **Default Repairability**: `manual`
- **Summary**: Unrecognized record participates in identity, parentage, pairing, or continuation.

## Invariant

All records participating in identity, graph parentage, tool pairing, or checkpoints must be recognized by the adapter.

## Cause

Proprietary or unknown third-party event records encountered in the session log.

## False-Positive Notes

Non-critical extension records (e.g. UI theme preference, non-semantic telemetry) can be ignored safely; only critical records trigger SL302.

**Privacy & Discriminator Bounding**: In finding evidence (`type_value`), benign unknown discriminators matching `^[A-Za-z0-9_.-]{1,64}$` are echoed verbatim for debuggability. Oversized or non-matching discriminator strings are redacted to `<type:len=N>` with `truncated: true` in evidence to eliminate credential and prompt leak vectors.

## Recipe or Manual Path

Manual review. Automated repair refuses modification of sessions containing unknown critical semantics.

Policy: *Unknown records participating in core semantics block automated repair.*

{"type": "unknown_critical_governance_record", "id": "rec_1"}
